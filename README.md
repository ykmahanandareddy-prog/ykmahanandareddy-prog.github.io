# MD developer website

Public developer website for Mahananda Reddy (MD), with Buffalo Run support and policy links.

GitHub Pages serves `main` from the repository root. `app-ads.txt` must stay at the root and contains the publisher's exact authorized Google seller record. There are no analytics, JavaScript dependencies, checkout, or private game source files in this website.

The Buffalo Run icon is copied byte-for-byte from the game's existing branding asset. The site describes the game as preparing for internal testing and does not advertise a public download or live purchase flow.
